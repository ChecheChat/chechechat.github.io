KOC 数字员工

2026.11 — 规划中做成工具讲出来给：泰国达人 BD 组

纯佣 KOC 量大、单个价值低，所以数字员工主做：写招募帖 → 发到 Facebook / LINE 群 → 达人填表 → 自动筛选打分 → LINE 官方号建联、发申样小程序 → 按规则批样 → 提醒发布 → 收视频、记履约 → 给客户周报。人只发 Facebook 帖、审核、处理例外。

纯佣 KOC 是批量招募、批量筛、批量寄样、批量催，人工跟不过来。设计上重复沟通全交数字员工，人只在发帖、审核、批例外、确认视频四个点出手。

我做的三个判断

  • KOL 和 KOC 分两套：一对一谈和批量招募逻辑不同，不硬合
  • 客户分级：重要、付费客户人跟，纯佣、低预算交数字员工
  • 先全审再放权：试跑期人全看，稳定后抽查，规则内自动通过
